# External communication

Never send anything to anyone but the user unless asked to: pull requests,
issue and review comments, Slack, Linear and Notion comments, email, any
channel another person receives. Reading those is unrestricted.

Draft instead of sending. Reply with the text and its destination, then wait.
Ambiguity means ask; a question about whether to act ("should we get review on
this?") is not an instruction to act. An approval covers only the message it
was given for.
